# M2：同周传播敏感性模拟

日期：2026-11-16。目的：在同周传播 w0 ≈ 0.3 与纯滞后基准 w0 = 0 的**匹配**对照下，量化 w0 对 QD-GMM（M0）估计、推断与 J 检验的影响。论文正文未改动。

## 设计

- 主设定：核心情景 `core_N500_T12_fb_spill`（N=500，T=12，G=50，φ=0.4，κ=−0.1，τ=log 0.8，NB k=10，feedback 采纳，α 缩放 0.25，gbar=0.1016），与 `experiment/code/scenarios.py` 一致。
- 两组：`benchmark`（w0=0）与 `same_week`（w0=0.3）。同种子（`20261112 + 1e5 + rep`）、同结构抽样、同处理规则（feedback）、同估计量（M0，φ̄=0.5）与同一 J 检验（M0-OI 两步法 Hansen J）。
- DGP（`same_week_dgp.py`）：周骨架与 `dgp.simulate` 相同；周生成间隔随 w0 调整为 `(0.85(1−w0), 0.15(1−w0))`，使滞后 1/滞后 2 之比在两组间恒为 0.85/0.15，估计窗的生成间隔不变。同周部分在估计窗第 3–12 周（代码中 0 起索引 j ≥ `ENGINE_FROM` = 2，即自第三个窗口周起，与正文 3.2.1 节一致）内按日生成再聚合：某日新增 = 外部传播（滞后 own + 邻居，均摊到 7 天）+ ω + 本周较早日期感染的周内再传播（率 c = w0·g/7）。周内再传播只作用于本单位；由此每周期望总量为周模型的 `exp(...)(L_p+ω)(1+w0·g)`，其中 `1/(1−c)` 型周内更新是周模型无法表达的项。
- w0 = 0 时不做日步，一次周 NB 抽样，与 `dgp.simulate` **逐位相同**（已验证 `Yall` 与 `Dall` 完全一致），因此基准组就是主模拟。
- 标定（`pretest.py` → `calib.json`）：g 取在核心情景上使“引擎/周模型”的均值比与处理份额比两项误差平均为零处，g = 1.744（周内再传播总量 A = w0·g ≈ 0.52）。在 g 处引擎两组周均值之比在窗口内由 0.70 上升到 1.42；处理份额 0.551 对 0.652。

## 运行

```bash
cd verification/same_week
python -I pretest.py                         # 重新标定 g（约 1 分钟，写 calib.json）
python -I sim.py --R 1000 --workers 16       # 主运行（约 5 秒），写 rows.jsonl
python -I aggregate.py                       # 写 results.json 并打印表
python -I robustness.py --R 1000 --workers 16  # 仅用窗口第 4–12 周重新估计，写 results_weeks4_12.json
```

`sim.py` 可重入：已完成的 rep 会跳过。`sim.py` 自动把 `experiment/code` 加入路径，调用其中的 `dgp.py`、`qdgmm.py`、`scenarios.py`；未修改这些文件。

## 解读与限制

1. **方向**：同周传播使 τ、κ、τ+κ 同时向下偏（τ 偏差约 0.033，是其真值 −0.223 的 15%，约 9 倍于偏差 MCSE；κ 偏差约 0.021，约 6 倍于 MCSE；τ+κ 偏差约 0.053，约 20 倍于 MCSE），φ 略上偏。τ 的覆盖率降到 0.89，τ+κ 联合区间降到 0.78。
2. **J 检验看不到它**：M0-OI 的附加工具变量来自预测期，不检验条件均值中的同周项，因此拒绝率不变。论文 Section "Transmission within a week" 关于“可能伤害推断、但需要专门设计来量化”的判断得到直接证据：偏差存在且可检测，论文中的过度识别检验发现不了。
3. **可归因性**：基准组逐位复现主模拟结果，两组只差 w0 与随之调整的周间隔归一化。
4. **预测试与设计效应的分量**：g 在核心情景上标定（20–40 次重复），同周组因此有更低的峰值与更长的上升段；这反映的是“忽略同周传播改变了周处理效应的识别条件”，即偏差本身的一部分，但混有预测试噪声。预测试网格显示：g = 1（A = w0，最自然的周内再传播量）时引擎均值比为 0.95、处理份额比 0.73；g = 1.744 使两项误差平均为零。稳健性运行（第 4–12 周）复现了同一方向与量级。
5. 估计窗第 1–2 周仍按周生成：它们的滞后 1–2 期进入采样周，而且第 3 周的同周部分来自第 2 周。同周组在这两周按周均值抽取同周量，不做日步。
