# 根选择规则（M0-GI）在新设计上的验证

日期：2026-11-13。目的：检验事后设计的根选择规则 M0-GI 能否在独立的新设计上复现其覆盖率增益。

## 设计

- 新种子基 `20270101`（开发阶段为 `20261112`），与开发数据完全独立；
- 9 个格子，每格 2000 次重复，共 18000 次；
- 扫描：φ₀ ∈ {0, 0.05, 0.10, 0.15}，参考值 φ̄ ∈ {0.25, 0.5, 1.0}，簇数 G ∈ {20, 50, 100}，采纳规则 {feedback, random}；
- 其余设置（DGP、生成间隔、α 缩放、gbar）与原文一致，gbar 取自 `analysis/results.json`。

## 判断

1. **φ₀ = 0 时 M0 失效、M0-GI 恢复到 0.888**，与原文（87.5%–95.2%）方向一致，并在新种子、新设计上复现。这是根选择规则有效性的直接证据。
2. **φ₀ = 0.05 时 M0-GI 覆盖率 0.912–0.929**，落在 95% 名义水平以下 2–4 个百分点；M0 在同样格子里是 0.957–0.967。**在真实耦合很小但非零的区间，M0-GI 反而比局部解更差**，因为它有 56%–79% 的概率把 φ 压到 0，从而在 φ ≠ 0 时引入偏倚。
3. **φ₀ ≥ 0.10 时 M0-GI 与 M0 几乎无差别**（覆盖率差 ≤ 0.03），边界选择率降到 30% 以下。
4. **结论**：M0-GI 不是一个无条件更好的选择。它只在 φ₀ 恰好在边界上时明显有利；φ₀ 略大于零时损害覆盖率；φ₀ 明显大时无影响。论文现有的“87.5%–95.2%”只覆盖了 φ₀ = 0 一个点，不足以支撑“可修复”的表述。
