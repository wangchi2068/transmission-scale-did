# 边界/弱识别下的稳健推断：可行性分析（M1）

日期：2026-11-16。只读分析：未修改论文正文，也未修改 `experiment/code/qdgmm.py`。复算脚本放在仓库外，依赖仓库 HEAD 版代码（`git show HEAD:experiment/code/qdgmm.py`）。

## 0. 结论

1. **数学上可做，但不是"直接换一个区间"**。在现有 `_solve_given_phi` 之上增加网格 profile、约束 AR-Wald 和邻域并集，即可得到对 $\phi_0=0$ 稳健的 $(\tau,\kappa)$ 置信集。核心新增约 100 行，属于"小改动"的范畴，但**必须**把 $\phi_r=0$ 的约束估计作为并集里的独立成员，并显式处理 $\phi$ 的边界。
2. **"projected AR（对 $\phi$ 做联合检验）"不可行**：$\phi=\phi_r$ 处三个参数矩均为 0，3 维最小化使 $Q\equiv0$，接受集退化为全集。只对 $\tau$ 做 AR 同样无效（等同 $\tau$ 的边际区间）。可用的做法是"按 $\phi_r$ 网格逐点做 $(\tau,\kappa)$ 的两自由度约束 Wald，再对邻域取包络"。
3. **$\phi_0=0$ 时的覆盖率可以修到接近名义水平**，修正量几乎全部来自把根放到边界（$\phi=0$ 约束估计）；AR 包络只解决"把哪些 $\phi_r$ 的区间并进来"的问题，且对 $\phi_0>0$ 有明确的宽度代价。数值：约束 Wald 覆盖率 0.98–1.00（$R=300$），M0 为 0.02–0.40，M0-GI 为 0.89–0.95。
4. **Oracle 覆盖不足不是选根问题**。Oracle 不估计根，`full.jsonl` 也不含 Oracle 字段，因此无法用 `full.jsonl` 区分两种机制。重放（种子与 `rsel_config.py` 一致）显示：Oracle 失败的分布**集中在尾部且双向对称、重尾**（cell 16，$R=400$：$|z|>1.96$ 为 18.8%，$|z|>2.5$ 为 11.2%，峰度 6.7）；$\phi$ 重估后该单元 $|z_\tau|>1.96$ 的比例降到 0。所以 Oracle 失败发生在**所有 $\phi_0=0$ 子样本的重尾尾巴里**，不在"选错根"的子样本里。它与 $T=26$、random adoption 下 $L_{it}$ 的周间噪声有关，由选根和区间方法都无法修复，需要模型层面的处理。

## 1. 现有 profile 机制

`experiment/code/qdgmm.py`：

- `profiled_eq(beta)`：给定 $\beta=(b,\phi)$，用周效应的闭式解（`_core` 里按周计算 $E_d$）把 $\delta$ 消掉，返回 $K$ 个参数矩方程与第 $K+1$ 个 $\phi$ 矩方程 $F_\phi$。
- `_solve_given_phi(mod, phi, x0)`（第 325 行）：固定 $\phi$，用 Powell hybrid 解 $K$ 个方程，返回 $(b, ok, F_\phi/f_{scale})$。这就是 profile 的骨架。
- `PHI_GRID`（第 310 行）：19 个点，$0\le\phi\le3$；边界只含 0，0 与 0.02 之间没有点，0.3 以上逐渐稀疏。
- `QDModel.moments(beta)`：返回矩贡献 $g_i$ 与完整雅可比 $J$（$(K+1)\times(K+1)$ 的参数块位于 `[T-1:, T-1:]`；`moments` 不显式给出周效应的 profile 雅可比，但 `inference()` 的 $V_b$ 使用的是完整 $(\delta,\beta)$ 雅可比）。
- `inference(beta)`：$V=(J'J)^{-1}\Omega\,(J'J)^{-T}/G\cdot G/(G-1)$，即 $J^{-1}\Omega J^{-T}/G$ 的等价形式，$t_{G-1}$ 区间。
- `fit_global(..., selection="oi"|"inv")`：网格扫描 + 符号变化 refine + $\phi=0$ 的边界候选 + 按 $Q$ 选根。边界选中时对 $(\tau,\kappa)$ 用 $\phi=0$ 固定推断，$\phi$ 的 SE 为 NaN。这一步已经给出边界约束估计，可复用。
- `verification/root_selection/rsel_run.py` 只记录 `tau0, se0, phi0, tau_gi, se_gi, phi_gi, at_boundary, n_roots`。`full.jsonl` 就是这些字段、9 格 × 2000 条，不含 Oracle 与约束估计。

## 2. 数学方案

### 2.1 不可行的构造（先排除）

设 $p=K+1=3$（$\tau,\kappa,\phi$）参数矩。在任意 profile 点 $\phi=\phi_r$，解出的 $(\hat\tau,\hat\kappa)$ 使三个参数矩 **恰好** 为 0。外推后的矩为 $\bar g(\beta_H)$；用增广估计 $\hat d=\arg\min_{d\in\mathbb R^3}\|\bar g+Jd\|^2_{\Omega^{-1}}$，在 $\hat d=0$ 处目标为 0，因此 $T_{\rm AR}(\phi_r)\equiv0$，接受集为全空间。数值上已确认这一退化。$|\hat\phi-\hat\phi_{j}|$ 与 $|d_\phi|$ 在 $\phi_r$ 处是同一个量，所以任何"以 $\phi$ 为联合检验维度、再投影到 $(\tau,\kappa)$"的构造都不提供筛选 $\phi_r$ 的准则，除非外加邻域或惩罚。

### 2.2 约束 AR-Wald（核心构件）

记 $g_r=\bar g(\hat b_r,\phi_r)$（profile 处 $\phi$ 矩为 0），$J_{b,r}=\partial\bar g_b/\partial b$（$p\times K$，由 `moments()['J']` 取列），$\Omega_r$ = $\phi_r$ 处的 cluster 矩协方差，$\Omega_r^{+}$ 为其伪逆（重根处 $\Omega_r$ 近奇异；当前 `inference` 用 `np.linalg.inv`，这是多根下 SE 虚低的根源之一）。

对 $H_0:(\tau,\kappa)=(\tau_0,\kappa_0)$、$\phi$ 自由但固定在 $\phi_r$：

$$
T_{\tau\kappa}(\phi_r)=G\,\hat d_r'\Omega_r^{+}\hat d_r,\qquad
\hat d_r=\big(J_{b,r}'\Omega_r^{+}J_{b,r}\big)^{-1}J_{b,r}'\Omega_r^{+}g_r ,
$$

在常规条件下 $T_{\tau\kappa}(\phi_r)\xrightarrow{d}\chi^2_2$；$(\tau,\kappa)$ 的接受集由

$$
[\,\hat\tau_r\pm c_2\hat\sigma_{\tau,r}\,]\times[\,\hat\kappa_r\pm c_2\hat\sigma_{\kappa,r}\,],\qquad c_2=\sqrt{\chi^2_{2,0.95}},\quad \hat\sigma^2 = \mathrm{diag}\big((J'\Omega J)^{-1}\big)/G
$$

给出（对应投影的包络）。这一步与"profile Wald"在单根处相同，在多根处则是"条件于该根"的 Wald。

### 2.3 并集构造

$$
C_{1-\alpha}=\bigcup_{\phi_r\in A}\Big[\,\hat\tau(\phi_r)\pm t_{G-1}\hat\sigma_\tau(\phi_r)\,\Big],\qquad
A=\{\phi_r:\ |\hat\phi_{j}-\phi_r|\le w\}\cup\{0\}\cup\{\text{边界候选}\},
$$

其中 $\hat\phi_j$ 是选定的根（M0 局部根、M0-GI 选择的根，或 $\arg\min$ profile 的根），$w$ 事先设定（例如 0.15），$\phi_r=0$ 强制纳入。若各根差异在尺度 $w$ 内，这就是对 profile 的局部近似；若根之间距离大于 $w$，则只取邻域内的根，避免把无关分支并进来（第 3.3 节：对 $\phi_0>0$，无限并集会过度覆盖）。

**$\phi$ 在边界时的修正**：$\phi=0$ 是模型的有效边界。报告时，在 $\phi=0$ 的约束 Wald 上使用 $\tfrac12\chi^2_1$ 的临界值（$z_{0.95}=1.645$），并单独给出去约束的 AR 区间。两种报告同时给出，作为边界稳健性的说明。

### 2.4 算法

```text
1  mod = QDModel(panel, spec_m0(panel, phi_bar))
2  for phi_r in grid (PHI_GRID ∪ {0, 0.03, 0.07, 0.12, 0.17}):
       b_r, ok_r, F_r ← _solve_given_phi(mod, phi_r, x0=上一个成功点)
3  Omega_r = cluster 协方差 at (b_r, phi_r);  J_b,r ← moments(...)['J'][T-1:, T-1:K+T]
4  T_{τκ}(phi_r) 按 (2.2);  tau/kappa 的 b_r ± t*se
5  约束 phi=0 成员:  _solve_given_phi(mod, 0)*  与  QDModel(phi_free=False, phi_fixed=0).inference()（现有 fit_global 的边界路径）
6  ref = 选定根;  A = {phi_r: |ref − phi_r| ≤ w} ∪ {0}
7  CI = ⋃_{r∈A} [b_r ± t_{G-1} se_r];  同时报告 profile 图、|A|、是否多根、phi=0 的 1/2 chi2 版本
```

**改动量**：新增 `profile_table`（约 30 行）、`constrained_ar`（约 50 行）、`union_set`（约 20 行），放在 `verification/root_selection/` 的新脚本即可，`qdgmm.py` 零改动。若放进 `qdgmm.py`，不影响任何既有签名。运行成本：单次重放约 0.11 s（实测 1500 次 / 20 核约 10 s），约为 `fit_global`（0.083 s）的 1.3 倍。

1. **选根错误**（M0 局部解停在错误根）——只影响 M0 / M0-GI，是 cell 8 的 0.361 和 0.89 的主要来源；
2. **边界 + $T=26$ random 下的重尾**——影响 Oracle，与选根无关，区间方法不能修复。

## 4. 回答问题

### Q1：能否用现有 profile 实现 AR / profile 型 $\phi$ 检验并取并集？

**可以，条件是检验的自由度取 $(\tau,\kappa)$ 两维，$\phi$ 维只能网格化。** 用 `_solve_given_phi` 在 $\phi_r$ 上得到 $(\hat b_r,F_\phi)$，再用 `moments()` 的 $J_b$ 与 cluster $\Omega_r$ 构成 (2.2) 的 $T_{\tau\kappa}(\phi_r)$，按 (2.3) 对邻域取包络，强制包含 $\phi=0$。这三步**不需要改任何既有函数**，新增约 100 行，属于小改动。

不可行的替代：3 维联合 AR（$Q\equiv0$）、单独 $\tau$ 的 AR（无检验力）、无邻域的"全 profile 并集"（$\phi_0>0$ 时过度覆盖）。

### Q2：$\phi_0=0$ 时覆盖率能否修到接近名义水平？

**能修到 0.95–1.00，但修正量主要来自"选边界"这一判断，而不是来自 AR 构造本身。** 约束 $\phi=\kappa=0$ 的 Wald 覆盖率 0.98–1.00；邻域包络 0.97–1.00（宽度为 M0-GI 的 1.0–2.3 倍）。对多根但真根不在边界的单元（$\phi_0=0.05$），约束估计会带入偏倚（README：M0-GI 在边界选择 56%–79% 时覆盖 0.91–0.93）；这些单元应保留 M0 的局部根，包络只在 $\hat\phi_j$ 邻域内并入根。这与 paper 现有建议（只在 profile 多根时才全局搜索，而非默认）方向一致。

### Q3：Oracle 的不足发生在选错根的子样本还是所有子样本？

**不是选错根。** Oracle 与根无关，`full.jsonl` 也不含 Oracle。重放显示：cell 16 的 Oracle $z$ 双向重尾（SD 1.73、峰度 6.65），cell 14/16 的 Oracle 覆盖 0.81/0.80，与官方 0.8055/0.8025 一致；$\phi$ 重估后同一批数据的 $|z_\tau|>1.96$ 比例降到 0–2%。因此 Oracle 的失败发生在**所有 $\phi_0=0$ 子样本的尾部**，在 $T=26$、random 下被放大；选根错误的机制只解释 M0/M0-GI 的覆盖率（cell 8 局部解的中位 $\hat\phi=0.485$）。

**对论文表述的含义**：把"Oracle 不足"与"选根"并列叙述并不成立；Oracle 不足的实证特征是重尾 Wald（$\phi_0=0$ 处 $\tau$ 的 $t$ 分布峰度 6.7），与 $\phi$ 的条件强弱识别无关。这部分不能靠 AR/profile 区间修补。

## 6. 建议

1. 报告顺序：先给 profile 图与"$\phi$ 是否在边界、是否多根"；$\phi_0$ 在边界时给 $\phi=\kappa=0$ 约束区间（用 $\tfrac12\chi^2_1$），并与 M0 局部区间并列；多根时在 $\hat\phi_j$ 邻域 $w$ 内并集，把 $w$ 与网格一起写进报告。
2. 不要把"全 profile 并集"作为主结果：$\phi_0=0.15$ 时过度覆盖、宽度增加 25% 以上。
3. 关于 Oracle：若要写进正文，应写成"$\phi_0=0$、$T=26$、random 下 Oracle Wald 统计量重尾（峰度约 6.7），且双向"，而不是"Oracle 在选错根或弱识别下失效"。
4. `rsel_run.py` 增加 Oracle 与约束估计字段后，可在同一批 2000 次重放中直接复验第 3.2 节。
