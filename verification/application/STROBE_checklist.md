# STROBE checklist for the mask-order application

Item numbers follow STROBE (von Elm et al., 2007) for cross-sectional/cohort observational studies.

| Item | Where it is reported |
|---|---|
| 1 Title and abstract | Abstract; Section 4 title names the design, the exposure and the outcome |
| 2 Background/rationale | Section 1, paragraphs 1–4 |
| 3 Objectives | Section 1, last paragraph; Section 4.1 |
| 4 Study design | Section 4.1, county-week panel, 26 weeks |
| 5 Setting | Section 4.1.1: 3091 counties in 49 state clusters, 2020-06-01 to 2020-11-23 |
| 6 Participants | Section 4.1.1 (units and clusters); no exclusion beyond Alaska, Hawaii and territories |
| 7 Variables | Section 4.1.2: outcome, exposure, covariates (week effects, lagged pressure, neighbours' policy) |
| 8 Data sources/measurement | Section 4.1.1–4.1.3; `experiment/data/data_contract.md` |
| 9 Bias | Section 4.1.2 (opt-outs not coded; exposure overstated); Section 4.2.2 (ascertainment) |
| 10 Study size | Section 4.2.1: 3091 units × 26 weeks; all available counties in the window |
| 11 Quantitative variables | Section 2.1: counts enter multiplicatively through the renewal mean |
| 12 Statistical methods | Sections 2 and 4.1.4: QD-GMM, state clustering, t_{G−1}, J test, sensitivity analyses |
| 13 Sensitivity analyses | Section 4.2.3: generation interval, network, policy timing, background input, reference value, excluded states |
| 14 Descriptive data | Section 4.2.1 |
| 15 Outcome data | Section 4.2.1: 11,528,182 cases |
| 16 Main results | Section 4.2.2 and Table 3 |
| 17 Other analyses | Sections 4.2.2–4.2.4: comparators, event time, lead regression, cases averted |
| 18 Key results | Section 4.2.2 and Discussion |
| 19 Limitations | Section 5, "Scope of the evidence" and "Reading the application" |
| 20 Interpretation | Section 5 |
| 21 Generalisability | Section 5 |
| 22 Funding | Back matter |
