\section*{Data Availability Statement}
All data used in the application are publicly available. Weekly case counts were derived from the
Johns Hopkins University CSSE COVID-19 repository \citep{dong2020dashboard} and mask orders from
the CDC Public Health Law Program \citep{cdc2021maskorders}. The county adjacency file and
county-to-county commuting flows are from the US Census Bureau. Code that downloads the data, verifies file checksums, reproduces
the simulation study and the application, and regenerates every table and figure is provided as
part of the reproducibility package accompanying this article.
