\section*{Data Availability Statement}
All data used in the application are publicly available; sources, checksums and the coding of
exposure are described in Web Appendix D. Code that verifies the file checksums,
reproduces the simulation study and the application, and regenerates every table and figure is part
of the reproducibility package accompanying this article.

\section*{Supporting Information}
Web Appendices A--E (regularity conditions and proofs, numerical checks of the theoretical results,
supplementary simulation results, data sources and cleaning, and few-cluster inference), referenced
in Sections~\ref{s:intro}--\ref{s:discussion}, are available as Supporting Information accompanying
this article, together with the reproducibility code and completed STROBE checklist
(\texttt{verification/application}).
