# experiment/ — code and data for the QD-GMM paper

Python 3.11; dependencies are pinned in `requirements.txt`. The design, deviations and the
protocol record are in `../analysis/experiment_design.md`; data provenance, checksums and the
mask-order coding are in `../data/data_contract.md`. Run scripts on the Windows development
machine use `python -I` so that a local file cannot shadow an import.

## Layout

| path | role |
|---|---|
| `qdgmm.py` | **proposed estimator**: QD-GMM (M0), M0′, M0-ET, M0-OI (two-step + Hansen J), M0-G (global root selection), M0-GI (post hoc selection) |
| `psi.py` | counterfactual recursion ν(θ), cases averted ψ (treated / network) with delta-method SE |
| `comparators.py` | M1 Poisson FE, M1-BC split-panel jackknife, M2 log R DiD, M3 log(Y+1) TWFE, M4 pooled QMLE, Oracle |
| `dgp.py`, `scenarios.py` | data-generating mechanism and the 25-scenario table; seeds; worker count |
| `simulate.py` | resumable multiprocessing Monte Carlo runner → `sim/rows.jsonl` |
| `aggregate.py` | performance measures + MCSE from whatever rows exist → `results.json`, `sim/metrics.csv` |
| `make_tables.py`, `make_figures.py`, `style_kit.py` | LaTeX tables and PDF/PNG figures from `results.json` |
| `data_prep.py` | raw files → `data/processed/panel.npz` (run with `python -I`) |
| `application.py` | application: main analysis, comparators, M0-ET and the revised M0-ET, sensitivities → `application/application_results.json` |
| `benchmark.py` | timing/memory per scenario → `run_plan.json` |
| `calibrate.py`, `pilot_alpha_tails.py` | pilot calibration (`calibration.json`) and the ALPHA_SCALE evidence (`../logs/`) |
| `../theory/numeric_checks.py` | numerical checks of the derivations in Web Appendix B (`python -I ../theory/numeric_checks.py`) |

There is no `run_all.sh`, `src/` package or `tests/` directory in this distribution. The stages are
run directly:

```bash
python -I simulate.py --workers 16        # Monte Carlo rows (resumable)
python -I aggregate.py                    # results.json + metrics
python -I make_tables.py --outdir ../tables --results ../analysis/results.json
python -I application.py --out ../application/application_results.json
python -I ../theory/numeric_checks.py     # Web Appendix B checks
python -I ../../verification/root_selection/build_rsel_table.py   # Web Table 7
```

BLAS/OpenMP threads are pinned to 1 inside the estimators' entry points.

## Results files

* `results.json`: per-scenario performance measures with MCSE, the application block and the
  protocol metadata.
* `../tables/manifest.json` lists each table with its sha256; tables are generated by
  `make_tables.py` and `build_rsel_table.py` and are not edited by hand.
